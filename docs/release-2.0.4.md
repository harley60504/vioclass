# VioClass 2.0.4

## DVR 與聊天室

- DVR 回放聊天室改用與進度列一致的播放時間，包含拖曳進度與從 mini 播放器返回。
- 跳轉時間後忽略過期的聊天載入結果，避免舊資料覆蓋新位置。

## 導覽與操作

- Windows 一般視窗的返回／首頁移至外框；全螢幕與手機仍保留播放器內導覽。
- 修正外框導覽按鈕的提示文字造成 Overlay 紅字錯誤。
- 追隨與瀏覽頁的實況主頭像、名稱、帳號及同列留白皆可開啟 About；縮圖與直播標題仍開啟直播。
- 手機可滑動查看播放器下方的頻道內容，再向下滑回播放器。
- 連續雙擊快轉／倒轉時，提示累積顯示秒數。

## 安裝

- Android：下載 `VioClass-2.0.4.apk` 安裝或覆蓋更新。
- Windows：下載 `VioClass-2.0.4-windows.zip`，解壓縮後執行 `vioclass.exe`。

本次不宣稱修復未能穩定重現的黑畫面或直播播放清單 HTTP 400 問題。
