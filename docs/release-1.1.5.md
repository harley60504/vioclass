# VioClass 1.1.5

這次更新主要改善 Twitch 直播的時間軸、短時間回看與背景恢復穩定性。

## 直播播放與時間控制

- 修正直播時間軸可能被異常時長污染，導致顯示 25、26 小時且無法恢復的問題。
- 改善直播結束、無 DVR，以及 DVR／VOD 需要訂閱時的狀態判定。
- 無 DVR 直播保留約 22 秒的 segment 歷史緩存，控制列可精細拖曳約 20 秒。
- 前後 10 秒操作會限制在開台起點與 Live 邊界；超過 20 秒時，有 DVR 的直播會切換至 DVR。
- 調整 Live segment 預抓數量，提升播放順暢度。

## 背景恢復

- 回到前景時保留播放器畫面，讓代理串流重新銜接最新 HLS segment。
- 先觀察播放進度，只有仍未前進時才重新開啟播放器，減少不必要的閃爍。
- 改善背景返回後重複 segment、短暫停頓與直播掉幀情況。

## 下載

- Android：下載 `VioClass-1.1.5.apk` 安裝。
- Windows：下載 `VioClass-1.1.5-windows.zip`，解壓縮後執行 `vioclass.exe`。
- 已安裝舊版的使用者也可以從設定檢查更新。
