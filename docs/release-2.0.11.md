# VioClass 2.0.11

## 繁體中文

- 重新整理播放器上方資訊：放大頭像與標題、移除資訊區底框，操作按鈕只顯示圖示，並加入 Twitch 合作夥伴的紫色認證標記。
- 控制列不再重複放置 Home／返回按鈕，保留系統手勢與 Windows 外框導覽。
- Windows 通知改為緊湊清單，面板隨內容縮放；點擊外部可收起，並修正滑過關閉按鈕時的顯示錯誤。
- Android 可選擇背景播放，並從媒體通知播放、暫停、快退／快進及拖曳 VOD／DVR 時間條；各類通知統一使用 VioClass 圖示。
- 改善 PiP 切換、背景返回播放與聊天室重連；返回播放頁會自動播放，直播恢復即時位置，回放接續進度。
- 改善追隨頁更新時的畫面保留，減少不必要的整頁重新載入。
- 改善直播片段中斷時的有限重試，以及 Windows Chroma Enhance 的顯示相容性。
- 將悄悄話、剪輯、賽況預測、忠誠點數和表情符號等中英文用詞與 Twitch 統一。

## English

- Refreshed player header with larger avatars and titles, icon-only actions, and verified Twitch Partner marks in the player and About views.
- Removed duplicate Home/Back controls from the player while retaining system gestures and Windows frame navigation.
- Compact Windows notification history that fits its contents, dismisses on outside clicks, and fixes close-button hover rendering.
- Optional Android background playback with media notification controls, VOD/DVR seeking, and a consistent VioClass notification icon.
- Improved PiP transitions, foreground playback recovery, and chat reconnection. Returning to the player resumes playback, recovering the live edge or retaining replay progress.
- Preserved Following content during refreshes, added bounded recovery for interrupted live segments, and improved Windows Chroma Enhance compatibility.
- Aligned common Chinese and English terminology with Twitch, including Whispers, Clips, Predictions, Channel Points, and Emotes.
