# VioClass 2.0.3

## Mini 播放器與聊天室

- 修正從 mini 播放器返回直播時，DVR 錄影資料被誤當成 VOD 入口的問題。
- 修正同帳號重新驗證時，聊天室誤判為身分變更而被清理的問題；真正登出或換帳號仍會清理舊連線。
- 即時聊天室連線不再等待歷史訊息查詢完成。
- 第三方與官方歷史訊息獨立補載，徽章不再等待額外的官方歷史查詢。
- 補載歷史訊息時保留現有訊息並去除重複；忽略舊連線延遲回來的資料。

## 安裝

- Android：下載 `VioClass-2.0.3.apk` 安裝或覆蓋更新。
- Windows：下載 `VioClass-2.0.3-windows.zip`，解壓縮後執行 `vioclass.exe`。

歷史訊息數量仍取決於來源是否有資料。本次不包含直播播放清單 HTTP 400 的修復。
