# VioClass 1.2.4

## 本次更新

- 加入 Twitch 私訊對話、本機紀錄及歷史同步，改善重複訊息、同步提示與閱讀位置。
- 整合聊天室與私訊貼圖選擇器，改善分類與輸入區佈局。
- 擴充聊天室管理、AutoMod、使用者資料、徽章展示與聊天串操作。
- 加入桌面與平板追隨中直播的快速切換列，改善內部通知與外框操作。
- Windows 登入使用 App 內 WebView，沿用既有 Cookie，並在同一登入流程完成主授權及 Drops。
- 修正登入新視窗處理：保留原登入頁，以真正的子 WebView 承接網站開啟的空白視窗與後續跳轉。
- 改善私訊驗證資料更新與 Windows WebView environment 釋放相容性。

## 下載

- Android：`VioClass-1.2.4.apk`，使用既有正式版簽章，可覆蓋安裝。
- Windows：`VioClass-1.2.4-windows.zip`，解壓縮後執行 `vioclass.exe`。
- 使用 GitHub Actions 建置，更新頻道為正式版（stable）。

## 建議驗證

- Windows 登入的 Google 子視窗、主授權與 Drops 完成流程。
- Android 登入、覆蓋更新與既有帳號資料保留。
- 私訊收發、歷史同步、重新開啟 App 後的驗證更新。
- 聊天室貼圖、聊天串、使用者徽章及具權限帳號的管理功能。

第三方網站登入及管理權限仍取決於網站回應與帳號狀態；自動測試通過不等同所有真實帳號流程都已驗證。
