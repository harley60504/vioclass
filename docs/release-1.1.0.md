# VioClass 1.1.0

這次更新主要整理播放器、背景恢復與動態貼圖體驗。

## 播放器與時間控制

- 整理直播、DVR、VOD 與 Clip 的播放狀態及返回流程，改善切換內容後回到前景出現舊畫面的問題。
- 調整 mini-player、Android 子母畫面與背景恢復的播放狀態同步。
- 整理 DVR 與直播的代理播放流程，以及拖曳、手動輸入時間和前後 10 秒操作。
- 統一播放器時間顯示，保留秒數，並改善控制列狀態同步。

## 聊天室與貼圖

- 修正部分 Twitch 動態貼圖只顯示靜態畫面的問題，包含 corgiHHH。
- 聊天室與貼圖選單共用動態貼圖顯示方式，解碼結果可重複使用。

## 下載

- Android：下載 `VioClass-1.1.0.apk` 安裝。
- Windows：下載 `VioClass-1.1.0-windows.zip`，解壓縮後執行 `vioclass.exe`。
- 已安裝舊版的使用者也可以從設定檢查更新。
