# 左側追隨直播頭像列

- 首頁與觀看頁共用 `TwitchFollowedLiveRailShell`，收合寬度 60px，滑鼠移入展開至 280px，移開收回。主內容固定只保留 60px 空間；展開部分以 Stack 半透明覆蓋，不改主畫面位置或寬度，不觸發播放器／聊天室重新縮排；背景 alpha 0.85。
- 顯示條件：寬度至少 1024px，或最短邊至少 600px 且寬度至少 760px 的平板；手機（含一般橫向手機）及窄版平板不固定顯示。全螢幕隱藏並停止頭像列的輪詢。
- 來源為既有 OAuth `streams/followed`；取得全部分頁、按 API 原順序去重，再用既有 users 查詢補頭像。沿用 `user:read:follows`，沒有新 GQL、scope、token 保存或持久資料。
- 顯示時載入，每兩分鐘更新；被其他 route 蓋住時跳過本列的定時載入。載入失敗清除本列並提供重試，不以另一個帳號的舊列表作成功資料。
- 目前觀看頻道用紫色外圈；點同一頻道不重載。滑鼠停留／平板長按顯示名稱與標題。清單獨立垂直捲動。
- 正常狀態不再有上方直播圖示列；展開列顯示實況主名稱、遊戲與帶千分位的觀看人數／紅點。只有載入失敗時提供重試入口。
- 首頁沿用 WatchRouteGuard 開台。觀看頁先呼叫既有 stopCurrentSession 清理聊天室、點數、關係及貼圖，再以新 WatchRouteGuard 取代目前觀看路由，不累積切台返回堆疊；未修改播放器底層 runtime。
- 兩份回歸測試：UI 尺寸／選取／提示／捲動／下播更新／全螢幕停輪詢／晚回應隔離，以及全部分頁／原順序／去重／重複 cursor 拒絕。新增滑鼠展開／收合、非浮層內容位置及半透明背景測試後，共 10 項通過。
