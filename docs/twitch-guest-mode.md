# Twitch 訪客模式

## 行為範圍

- 未登入可使用「瀏覽」、遊戲分類、語言篩選與頻道搜尋。
- 公開探索資料使用 Twitch Android 公開 Client-ID 的無 OAuth GQL；不內嵌 client secret，也不借用其他帳號 token。
- 未登入可進入公開直播；播放器的登入 token／匿名播放選擇由既有播放 runtime 管理。
- 公開錄影、剪輯清單與 DVR 錄影查詢不要求登入；保留錄影建立時間與秒數，供既有 DVR 判定使用。
- DVR 仍需頻道提供本場正在增加的公開錄影；沒有錄影或錄影被限制，不會假裝 DVR 可用。播放授權限制仍由原有播放器處理。
- 身分尚在讀取／聊天室連線時，觀看頁不會以空 viewerId 判成訪客；追隨、訂閱、建立剪輯暫停操作，待判定完成。
- 未登入聊天室以匿名 IRC 唯讀連線；畫面不提供發言、頻道點數或聊天身分操作，改顯示登入按鈕。
- 追隨頁、追隨／取消追隨、訂閱、建立剪輯、私訊、Drops 與帳號互動維持登入需求。
- 訪客模式不建立本機收藏，也不把空資料假裝成已同步的追隨清單。

## 自動測試

執行：

```text
flutter test docs/twitch_guest_mode_test.dart
flutter test docs/twitch_guest_media_test.dart docs/twitch_discovery_session_test.dart
```

選擇性真實接口測試（會連線 Twitch，不使用帳號 token）：

```text
flutter test --dart-define=TWITCH_GUEST_LIVE_TEST=true docs/twitch_guest_media_test.dart
```

測試涵蓋：

1. 公開 GQL 直播資料、標籤、縮圖、頭像與下一頁 cursor 映射。
2. 公開頻道搜尋正確拆分直播中與離線頻道。
3. 訪客聊天室顯示唯讀說明、沒有輸入框，且登入按鈕可觸發登入流程。

## 實機驗收清單

1. 清除／登出 Twitch 帳號後啟動 App，追隨頁顯示登入需求，不顯示假的追隨內容。
2. 切到「瀏覽」可看到公開直播；遊戲、語言、分頁載入與下拉重新整理可用。
3. 搜尋實況主時可看到直播中與離線頻道；點公開直播可進觀看頁。
4. 觀看頁可匿名開始播放，且不要求先登入。
5. 聊天訊息可持續讀取；底部顯示「訪客模式可讀取聊天室」，不出現可輸入的發言框。
6. 點聊天室登入、追隨、訂閱或建立剪輯時進入既有 Twitch 登入流程。
7. 登入完成返回觀看頁後，聊天室重新以該帳號連線，發言與帳號互動恢復。
8. 私訊與 Drops 仍使用既有授權頁，不會顯示成已登入或繞過權限。
9. 同一個有公開 DVR 的頻道，登入與登出都可讀取錄影並回放；另測沒有公開錄影／限制錄影的頻道。

## 訪客限制檢查

- 公開瀏覽、直播、錄影、剪輯、聊天室閱讀及播放控制應可匿名使用。
- 發言、追隨、私訊、點數寫入、建立剪輯與管理操作需帳號／權限。
- 播放控制鍵盤操作不檢查登入；聊天室管理捷徑仍在执行前檢查管理 API 與 canModerate，不能繞過權限。
- 公開瀏覽的缺漏頭像補資料亦走匿名查詢。遊戲 ID 批次補資料只用於已登入的追隨頁，維持原有 Helix 流程。
