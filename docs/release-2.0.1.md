# VioClass 2.0.1

## 播放控制與手勢

- 精簡單排控制列，調整窄視窗下的左右控制區與中央時間對齊。
- 移除控制列快轉／倒退按鈕，改用左右方向鍵與影片左右雙擊跳轉 10 秒。
- 加入影片水平拖曳：先預覽時間，放開才跳轉，取消觸控不會跳轉。
- 快捷鍵、雙擊與拖曳皆預設開啟，可在「播放器 → 播放手勢與快捷鍵」各別關閉。
- 音量改成單一按鈕，點開面板後拖曳滑桿調整音量。
- 20 秒回看與直播狀態標記改為同尺寸圓形圖示，保留提示文字。

## 介面與建置修正

- 統一個人資料面板私訊與關閉按鈕的高度及圓角。
- 改善 Windows 播放器套件快取辨識、下載等待上限與不完整快取處理；保留校驗碼驗證。

## 安裝

- Android：下載 `VioClass-2.0.1.apk` 安裝或覆蓋更新。
- Windows：下載 `VioClass-2.0.1-windows.zip`，解壓縮後執行 `vioclass.exe`。

手勢只作用在影片區；無可跳轉內容時不會強制跳轉。直播回看範圍仍依來源與播放狀態而異。
