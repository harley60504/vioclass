# VioClass 2.0.7

- 改善直播從背景返回後的同步：真正回到前景時重新連接直播串流並重開播放來源，避免只因影片仍在播放就繼續消耗舊內容。
- 統一各平台的背景返回處理，不再依背景時間長短決定是否恢復直播；單純失去焦點不觸發重連。
- DVR／VOD 保留原本觀看位置，不強制跳回直播。Windows 維持 App 內通知，未新增系統通知註冊設定。

驗證：17 項觀看流程回歸測試通過；Windows 原生播放器搭配受控背景事件，確認 Windows／Android 分支皆重新接流並繼續解碼，焦點切換不重開、DVR 不重開。此為電腦受控測試，尚未驗證 Android 平板真實 Twitch 串流的背景延遲。
