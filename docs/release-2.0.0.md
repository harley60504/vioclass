# VioClass 2.0.0

這次是整體體驗更新，涵蓋訪客瀏覽、直播控制、聊天室與私訊。

## 主要更新

- 調整登入狀態與訪客使用流程，改善瀏覽、搜尋及追隨頁面體驗。
- 更新直播／VOD 控制列、時間軸與播放器設定介面。
- 統一聊天室與各個面板的標題列、圖示與外框，調大聊天文字基準。
- 個人資料與訊息面板分開：點人名看資料，點訊息看聊天串與已載入紀錄。
- 補充公開個人資料、徽章收藏、聊天顏色與 7TV 名稱樣式預覽；加入短暫快取。
- 改善私訊開啟時同步、未送出對話與草稿保留流程。
- 整理通知、音訊與背景執行設定。

## 安裝

- Android：下載 `VioClass-2.0.0.apk` 安裝或覆蓋更新。
- Windows：下載 `VioClass-2.0.0-windows.zip`，解壓縮後執行 `vioclass.exe`。

公開資料可能受來源可用性與權限影響；沒有回傳的欄位不會強行顯示。
直播可回看時間依來源與播放狀態而異，不保證每個頻道皆提供固定時長。

## 建置驗證紀錄

Windows 首次 CI 建置發現固定播放器套件的下載校驗碼與現存上游資產不符。
2026-10-13 對照 GitHub 官方 asset digest 並獨立下載驗證後，修正壓縮檔與 DLL 的 SHA256。
仍固定使用同一個 `2026-10-09-fd9265a905` LGPL x86_64 版本，保留雙重校驗，不改成 latest 或略過驗證。
